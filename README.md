# mtorch

A minimal homemade autograd & neural network framework implemented purely on NumPy.

## Overview

mtorch implements reverse-mode automatic differentiation, similar to PyTorch.

- Tensor with automatic differentiation
- Common activation functions & loss functions
- Linear layers, basic neural network modules
- Optimizers for parameter updates
- Pure NumPy backend, no extra heavy dependencies

## Installation

```bash
pip install mtorch
```
